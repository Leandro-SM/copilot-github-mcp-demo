# Guia de Contribuição

Obrigado por contribuir com este projeto de demonstração!

## Fluxo de trabalho

1. Crie uma branch a partir da `main`:
   ```bash
   git checkout -b feature/minha-feature
   ```
2. Faça suas alterações e commits descritivos.
3. Abra um Pull Request para a `main`.
4. Aguarde a revisão e aprovação.
5. Após aprovado, faça o merge.

## Padrões de commit

Utilize mensagens claras no formato:

```
tipo: descrição breve
```

Exemplos de tipos: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.

## Código de conduta

Seja respeitoso e colaborativo em todas as interações.
