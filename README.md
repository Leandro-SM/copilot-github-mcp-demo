# copilot-github-mcp-demo

Repositório de demonstração das ações que um **agente Copilot Studio** pode executar no GitHub por meio do **MCP (Model Context Protocol)**.

## Sobre o projeto

Este repositório demonstra, na prática, um fluxo de desenvolvimento autônomo ponta a ponta:

1. Criação de repositório
2. Criação de issues
3. Trabalho em branches dedicadas
4. Criação e atualização de arquivos
5. Commits
6. Abertura de Pull Requests
7. Revisão e aprovação
8. Merge automático

## Estrutura

```
.
├── README.md            # Este arquivo

└── examples/
```
